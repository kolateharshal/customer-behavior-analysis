Topic : Develop an Edge Impulse project (Smart-Vibration-Monitor) using sensor data and explain the role of sensor as edge devices.

Aim

To develop an Edge Impulse machine learning project using sensor data and understand the role of sensors as edge devices for real-time data collection, feature extraction, classification, and intelligent decision-making at the edge.

Introduction

Edge Impulse is an embedded machine learning platform used for developing and deploying AI models on resource-constrained edge devices such as microcontrollers and IoT systems. It provides an end-to-end workflow for collecting sensor data, extracting features, training machine learning models, and deploying them on edge hardware.

In this project, sensor data is collected from five different parameters—Temperature, Vibration, Pressure, RPM (Rotations Per Minute), and Torque—to monitor machine conditions. The collected data is classified into three categories: Failure, Normal, and Warning. The machine learning model is trained using Edge Impulse and optimized for real-time inference on edge devices.

Sensor Data Used

The following sensor parameters are used in the project:

Sensor Description
Temperature Measures heat generated by the machine.
Vibration Detects abnormal mechanical vibrations.
Pressure Monitors pressure conditions within the system.
RPM Measures the rotational speed of the machine.
Torque Measures the rotational force produced by the machine.

These sensors continuously collect real-time information and act as the primary source of data for the machine learning model.

Dataset Information

The dataset is divided into three machine conditions:

  • Failure
  • Normal
  • Warning

Dataset configuration:

  • Total Training Samples: 20
  • Total Testing Samples: 10
  • Dataset Split: 67% Training and 33% Testing
  • Duration of Sensor Data: Approximately 3 seconds per sample

The collected sensor readings are labelled before training the model to improve classification performance.

Edge Impulse Project Configuration

The project is configured using the following parameters:

Parameter Value
Input Axes 5 (Temperature, Vibration, Pressure, RPM, Torque)
Frequency 100 Hz
Window Size 1041 ms
Window Increase (Stride) 486 ms
Processing Block Flatten
Learning Block Classification
Output Classes Failure, Normal, Warning

The sensor data is divided into time windows before feature extraction and classification.

Feature Extraction

Feature extraction is an important step in Edge Impulse. The Flatten block converts raw sensor values into processed numerical features that can be used for machine learning.

The extracted features include:

  • Average values
  • Minimum values
  • Maximum values
  • Statistical characteristics of the sensor readings

Feature extraction helps in:

  • Reducing computational complexity.
  • Improving classification performance.
  • Preparing the data for neural network training.
  • Making the model lightweight for edge deployment.

The Feature Explorer in Edge Impulse provides a graphical representation of how different classes are distributed based on the extracted features.

Neural Network Architecture

The machine learning model consists of the following layers:

  • Input Layer: 35 Features
  • Dense Layer: 20 Neurons
  • Dense Layer: 10 Neurons
  • Output Layer: 3 Classes

The output layer predicts the machine condition as:

  • Failure
  • Normal
  • Warning

Training parameters used in the project are:

  • Number of Training Cycles: 50
  • Learning Rate: 0.0005
  • Training Processor: CPU

The neural network is optimized for deployment on low-power embedded devices.

Role of Sensors as Edge Devices

Sensors play a significant role in edge computing systems because they serve as intelligent edge devices that collect and process real-world information.

1. Real-Time Data Collection

Sensors continuously monitor physical parameters such as Temperature, Pressure, Vibration, RPM, and Torque. The collected data is immediately available for machine learning inference.

2. Edge Intelligence

Sensors enable intelligent processing at the edge by allowing data to be analyzed locally. Instead of transmitting all sensor data to cloud servers, the machine learning model processes the information directly on the edge device. This provides:

  • Faster predictions
  • Reduced latency
  • Improved system efficiency

3. Fault Detection and Monitoring

The sensor data helps in identifying different machine conditions such as Normal operation, Warning conditions, and Machine failures. This makes the system useful for predictive maintenance and industrial monitoring applications.

4. Low Latency Processing

Since the machine learning model runs on the edge device, predictions can be generated within milliseconds. Low latency processing is essential for Industrial automation, Smart monitoring systems, and Embedded AI applications.

5. Reduced Network Dependency

Processing data locally offers several advantages:

  • Reduced bandwidth consumption.
  • Improved privacy and security.
  • Lower power consumption.
  • No continuous internet connection is required.

This makes edge computing highly suitable for IoT applications.
